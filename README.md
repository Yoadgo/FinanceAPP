# FinanceAPP

אפליקציית ניהול פיננסי אישי — תיקי השקעות, מעקב תזרים והוצאות, התחייבויות וצבירה.
נבנית כאתר סטטי ומתארחת ב-GitHub Pages.

## מבנה

HTML / CSS / JavaScript טהורים, בלי ספריות חיצוניות ובלי שלב בנייה.
הנתונים יושבים ב-Google Sheets ונקראים דרך שכבת Google Apps Script שנמצאת בתיקיית `apps-script/`.

```
index.html          שלד הדף וסדר טעינת הקבצים
css/                variables · layout · components · journal · portfolio · pages
js/modules/         navigation · dataService · classifier · portfolioEngine · analytics
js/components/      dashboard · portfolio · journal · cashflow · performance
apps-script/        Code.gs — הגשר לגיליון (doGet בלבד כרגע)
```

סדר הטעינה ב-`index.html` קשיח: קודם המודולים, אחריהם `js/app.js` שמגדיר את מרשם הדפים
`Pages{}`, ורק אז קבצי המסכים — כל אחד רושם את עצמו למרשם.

## מסכים

- **לוח בקרה** — שווי נקי, רווח ממומש ולא ממומש, גרף הון מושקע מול שווי התיק
- **תיקי השקעות** — פוזיציות פתוחות, מחירים חיים, פילוח לפי נייר
- **ביצועים** — עסקאות סגורות, תשואות, מיסים
- **יומן תנועות** — כל התנועות עם סינון, מיון וחיפוש
- **הכנסות והוצאות** — תזרים המזומנים של הברוקר
- **חסכונות** — בבנייה

## מסמך האפיון

`מסמך אפיון FinanceAPP.html` בשורש הפרויקט מכיל את האפיון המלא: מודל הנתונים,
מנועי החישוב, שפת העיצוב ותוכנית הפיתוח המדורגת. הוא מקור האמת למה שנבנה ולמה.

## פריסה

הענף `main` מתפרסם אוטומטית ל-GitHub Pages.
בכל שינוי ב-JS או ב-CSS יש להעלות את מספר הגרסה `?v=` בכל תגי ה-script וה-link
ב-`index.html`, אחרת דפדפנים ימשיכו להגיש את הקבצים הישנים מהמטמון.

שינוי ב-`apps-script/Code.gs` **אינו** מגיע לייצור ב-push. צריך להדביק אותו בעורך
ה-Apps Script ולבצע פריסה של גרסה חדשה על אותה פריסה קיימת.
