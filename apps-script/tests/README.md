שמות של אנשים שלישיים. הריפו ציבורי, ולכן הקובץ ב-`.gitignore`.

בלעדיו שתי הבדיקות ייכשלו בקריאת הקובץ. לבנייה מחדש: ייצוא `FibiSave*.xls`
מהבינלאומי, ואז המרה לצורת התאים של Apps Script — מערך שורות, תאריכים
כאובייקטים `{"__d":"YYYY-MM-DD"}`, מספרים כמספרים.
